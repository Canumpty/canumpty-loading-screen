# Optional Media Assets

© 2026 Canumpty Digital Studios. All rights reserved except as expressly granted under this licence.

Put your own media here, then reference it from `../config.js`.

- Background image: `background.jpg`, `background.png`, or `background.webp` (16:9, ideally 1920×1080).
- Background video: `background.mp4` or `background.webm`.
- Music: `.mp3`, `.ogg`, or another browser-supported audio file.

The package includes a Canumpty Digital Studios starter background and the original track **Adrenaline Rush** so it works immediately after installation. Replace them with your own material if preferred. Only add media you own or are licensed to redistribute.
